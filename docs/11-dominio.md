## 2. Pontos de decisão antes de comprar

- [ ] **Extensão `.xyz` vs `.com`:** `.xyz` é mais barato, mas `.com` / `.com.br` passam mais confiança para um SaaS. Avaliar se `nexotec.xyz` é o domínio definitivo ou só uma reserva de baixo custo.
- [ ] **Verificar disponibilidade de `nexo.com.br`, `nexoapp.com.br`, `usenexo.com.br`** ou variações — domínio principal de marca importa mais que o preço.
- [ ] **Privacidade de domínio:** a GoDaddy oferece privacidade gratuita (WHOIS protegido). Manter ativada.
- [ ] **Conta:** comprar na **conta pessoal** (Nexo é projeto pessoal — guibesxo@gmail.com), nunca misturar com infraestrutura Prolog.
- [ ] **Renovação automática:** decidir se liga auto-renovação (evita perder o domínio) ou compra manual.
